# Modrinth gallery

Images are in `modrinth/gallery/` (1920×1080 JPG). Upload them in this order. ★ = set as the featured image.

Images 01–05 are **renders of the mod's real block models**, made in Blender. 01 and 02 rebuild a real Baker City station from its save file. The descriptions say so, so nobody mistakes them for in-game screenshots. Everything else is an in-game or browser capture.

| File | Title | Description |
|---|---|---|
| 01_subway_station.jpg ★ | A real station, built with the mod | Subway tile walls with a station-colour band, iron columns tinted to the station colour, and concrete platform floors. Rendered from a Baker City station's save. |
| 02_countdown_clock.jpg | NYC countdown clock | The hanging B-Division clock counting down live MTR arrivals. The row flashes when the train is in. Render; the screen is drawn the way the game draws it. |
